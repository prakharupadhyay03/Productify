# 🚀 Productify

Productify is a full-stack product sharing platform where users can create, update, and manage products with secure authentication and interactive comments.

Built to practice real-world full-stack development, authentication flows, database design, and production deployment.

---

## 🔧 Tech Stack

### Frontend
- React (Vite)
- Axios
- Clerk Authentication

### Backend
- Node.js
- Express.js
- Drizzle ORM

### Database
- PostgreSQL (Neon)

---

## ✨ Features

- 🔐 Secure authentication using Clerk
- 👤 User synchronization with database
- 📦 Product CRUD operations (Create, Read, Update, Delete)
- 💬 Comment system with relational queries
- 🛡️ Protected routes (only product owners can modify/delete)
- ⚡ Optimized queries using Drizzle ORM
- 🌍 Environment-based configuration (Dev & Production ready)
